# 🎂 Happy Birthday Aishwarya ✨

A magical, interactive birthday celebration website made with love for **Aishwarya**.

## ✨ Features
- 👑 Personalized greetings & celebration theme
- 🕯️ 3D Birthday cake with blowable candles (`HBD AISHWARYA`)
- 🎬 Atmospheric background video & cinematic video reel
- 📸 Cherished Memories Gallery with 100% uncropped photos and full-screen lightbox
- 🎈 Interactive balloon popping messages
- 🎁 Virtual 3D gift box with celebration promises
- 💌 Open-when digital letters
- ✨ Interactive scratch card coupons
- 🎵 Web Audio synthesizer playing the Happy Birthday melody
